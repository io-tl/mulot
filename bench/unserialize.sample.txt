### Vulnerability: PHP Object Injection → Remote Code Execution
**Severity: Critical**

The `drawing` cookie is deserialized with `unserialize()` without any validation:
```php
$drawing = unserialize(base64_decode($_COOKIE["drawing"]));
```

The page also defines a `Logger` class with a `__destruct()` magic method that writes `$exitMsg` to `$logFile`. By crafting a serialized `Logger` object where:
- `logFile` → `img/x.php` (a web-accessible path)
- `exitMsg` → `<?php system("cat /etc/natas_webpass/natas27"); ?>`

### Remediation
**PHP:** Never pass untrusted user input to `unserialize()`. Replace it with a safe format like `json_decode()`. If unavoidable, use `unserialize($data, ['allowed_classes' => false])` (PHP 7+) to block arbitrary object instantiation.
